游荡者 Rogue

游荡者在本节中获得了新的职业特性与子职选项。

可选职业特性 Optional Class Features

你在达到特定等级时会获得玩家手册中描述的职业特性。而本节提供了一些你作为游荡者时的额外特性。
与玩家手册中的特性不同的是，你不会自动获得这些特性。在你达到本节描述的职业特性的先决等级，并决定获得这些特性前，先与你的DM进行商议。这些特性可以被单独选取，这意味着你可以使用其中的某个或全部，又或是完全不用。

稳定瞄准 Steady Aim
3级游荡者特性
你能以附赠动作在当前回合为你的下一次攻击提供优势。你只能在你本回合还没有移动的时候使用这个附赠动作，而且在你使用这个附赠动作后，你的速度在当前回合里归0。
